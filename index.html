Fan Control

Version 1.5.0 · Free and open source

Fan controls for HP Victus and OMEN laptops on Linux.

Install with Flatpak Source code

Choose a thermal profile, toggle maximum fan speed, and monitor both fans’ RPM. Built with GTK 4 and libadwaita.

Installation

Open the .flatpakref in your software center, or run:

flatpak install --user https://sh7vansh.github.io/victus-fan-control/fan-control.flatpakref

Choose Enable Service, authenticate, and restart when prompted. Requires supported HP firmware, hp-wmi, systemd, polkit, coreutils, and a graphical authentication agent. Updates come from the signed Fan Control repository.

Using the app

On GNOME, the OMEN button opens Fan Control if the key was unassigned. After app updates, choose Update Service and restart. Choose Disable Service before uninstalling to remove the host service.

Maximum fan speed stays active after closing. Turn it off to restore automatic cooling. Available controls depend on your firmware.

The app runs commands on the host as your user, which software centers label “Potentially Unsafe.” Cooling changes use a root-owned service accessible to your account and root.
