Fan Control

Version 1.1.0 · Free and open source

Manage cooling on HP Victus and OMEN laptops with a native GTK 4 and libadwaita app.

Install with Flatpak Source code

Choose a firmware thermal profile, switch both fans to maximum speed, and check live fan RPM. The app follows your desktop’s light or dark appearance.

Version 1.1.0 lets you authenticate once per app session, then adjust cooling without repeated prompts. Use Lock Fan Controls in the menu to lock the session again.

Installation

Open the downloaded .flatpakref in your software center. It adds the signed Fan Control repository for future updates. You can also run:

flatpak install --user https://sh7vansh.github.io/victus-fan-control/fan-control.flatpakref

A separate RPM or service is not needed. Supported HP firmware, Python 3.10+, polkit, coreutils, and a graphical authentication agent are required on the host.

Host access and cooling

The app has permission to run host commands as your user. Your software center accurately labels this as potentially unsafe. The first fan change requires administrator authentication through polkit. The temporary fan-control helper handles later changes in the same app session and exits when you close or lock it. Your password is handled by the system.

Maximum fan speed remains active after closing the app. Turn it off to restore automatic cooling. Available profiles and fan controls depend on the laptop’s firmware and Linux driver. Screenshots show live readings from an HP Victus. Fan speeds vary with workload and temperature.
